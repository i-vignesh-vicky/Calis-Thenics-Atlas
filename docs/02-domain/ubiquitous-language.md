# Ubiquitous Language

## Purpose

Define shared domain vocabulary used by product, engineering, analytics, and AI systems. If a term conflicts with implementation details, business meaning takes precedence.

## Core Terms

- User: Person using the platform.
- Athlete: User actively training toward measurable outcomes.
- Workout Session: In-progress training activity.
- Workout: Completed, historical training record.
- Routine: Reusable planned workout template.
- Program: Time-structured training plan with progression intent.
- Exercise: Movement definition (metadata).
- Set: Performed unit of an exercise (reps/load/duration).
- Skill: Capability requiring progression stages.
- Milestone: Meaningful achievement event.
- Progress: Improvement relative to user's own history.
- Recovery: Estimated readiness based on load and context.
- Streak: Continuous adherence sequence.
- Challenge: Time-bound objective with measurable rules.
- Community Post: User-shared content.
- AI Recommendation: Explainable guidance, not command.

## Language Rules

1. Use "workout" only for completed sessions.
2. Use "workout session" for active/incomplete flows.
3. Use "progress" as self-referenced, not social comparison.
4. Use "recovery" as estimate with uncertainty.
5. Use "milestone" for discrete achievements, not generic updates.
