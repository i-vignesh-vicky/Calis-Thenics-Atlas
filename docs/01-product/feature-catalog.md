# Product Capability Catalog

## Purpose

This catalog defines major product capabilities, their value, MVP scope, and evolution direction.

## Core Capabilities

1. Identity and access
2. User profile and goals
3. Exercise library
4. Programs
5. Routine builder
6. Workout execution and logging
7. Skills and milestones
8. Progress and consistency
9. Community and challenges
10. Notifications and search
11. AI and personalization foundations

## MVP Capability Detail

### Identity and access

- Email registration/login
- Password reset
- Session handling

### User profile and goals

- Basic profile
- Training goals
- Experience level
- Equipment context

### Exercise library

- Searchable movement catalog
- Instruction and difficulty metadata

### Programs

- Browse and enroll
- Track program progress

### Routine builder

- Create, edit, duplicate, archive
- Ordered exercise structure

### Workout execution and logging

- Start/pause/resume/complete
- Set-level logging
- Notes and RPE

### Skills and milestones

- Skill stages
- Milestone tracking

### Progress and consistency

- PR tracking
- Timelines
- Streaks

### Community and challenges

- Profiles, posts, comments
- Join and track challenges

### Notifications and search

- Reminder and social notifications
- Search users/exercises/programs

### AI foundations

- AI-ready event and history capture
- No advanced AI coaching in MVP
