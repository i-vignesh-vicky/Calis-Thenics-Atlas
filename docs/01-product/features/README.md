# Product Features

This folder contains detailed functional requirements for all Atlas product capabilities.

For the full feature index, navigation, dependency map, and roadmap context, see the [Feature Catalog](../feature-catalog.md).

## Folder Convention

Each subfolder is named `NN-feature-name/` and contains:

- **functional-requirements.md** — Detailed requirements, user flows, acceptance criteria, data models, edge cases, MVP scope, and future enhancements.
