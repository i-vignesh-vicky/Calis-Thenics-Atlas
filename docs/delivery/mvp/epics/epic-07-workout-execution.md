# Epic 07 — Workout Execution

## Purpose

Deliver the core training experience: users can start, log sets, pause, resume, complete, and auto-save workout sessions from a routine.

## Functional Requirements Satisfied

| FR ID | Requirement |
|---|---|
| FR-WORKOUT-001 | User can start, pause, resume, and complete a workout session |
| FR-WORKOUT-002 | User can log set-level reps, load, and duration |
| FR-WORKOUT-003 | System auto-saves the in-progress workout session |
| FR-WORKOUT-004 | Completed workout is stored in history |
| FR-WORKOUT-005 | User can add notes and perceived exertion |

Detailed requirements: `docs/01-product/features/06-workout-execution/functional-requirements.md`
